# 混合环岛弯路接入平滑

用户已反馈上一包预览／放置无错误，要求继续改善曲线模式汇入外观。保持autochange/0.0.1-beta，不提交、不强关游戏，不放宽原生检查。

1. 用最新日志的六个端点位置及朝向构建可控弯曲路廊（延伸曲线为测试构造，不声称完整实机重放），记录旧转换段的峰值曲率、曲率跳变和曲线图。
2. 保留已通过的原核心和真实切点。环岛的双向转换在旧安全候选之后，有界尝试沿实际原路选择内侧分叉位置／切向，以及曲率连续的分叉与连接控制点。每个完整候选均占共享预算，完整复查真实宽度、坡度、曲率、跨长、净空和桥墩。不能找到更平滑安全方案时返回旧候选。
3. 平滑评分覆盖双向干线、单向转换、它们相互之间、内部原核心接点及外侧保留原路的曲率跳变。只接受质量改善且峰值曲率不恶化的候选。
4. RED→GREEN外观回归、前后图、左右行／圆环／跑道及已有真实四端点回归、独立审查、Release和完整回归；正常关闭游戏后备份部署、核验27个文件。
