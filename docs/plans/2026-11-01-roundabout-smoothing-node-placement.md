# 环岛弯路接入优化与节点模式确认放置

目标：根据玩家截图优化环岛在真实弯路上的接入，并按其明确要求开放已实现节点类型的确认放置。autochange / 0.0.1-beta 不变，不提交、不推送。

状态：测试包已部署，等待首次游戏实际放置验收。48 项相关回归、2085 项全量回归、UI 类型检查/构建及 Release 构建通过；独立审查及可见修订号事件修正后的专项复核通过。游戏正常退出后已备份部署，27 个文件独立 SHA256 复核一致。

## 现状与根因证据

- 玩家确认环岛其他项目通过，截图的退接为200/0/175/25m，与已捕获弯路基准一致。
- EndpointRoundaboutSearch 目前直接返回共享 FindSafe 的第一个合格候选，短接路只满足最小半径/净空，没有使用已有 EndpointApproachQuality 比较外观；井字已有保留安全基准的有界质量改进流程。
- NodePreviewPlacer 已经在同一游戏临时定义批次中安排原路删除、新路和保留尾段；清除预览不会真的拆路。实际应用由游戏 ApplyMode.Apply 提交。节点模式当前在 UpdateNodeMode 丢弃确认请求、TryApply 返回null，UI没有确认入口。

## 决策与不变量

- 沿用既有节点方案B。新增环岛 fitter：先保留安全基准，再按同一128个完整候选总预算，尝试更长/成对协调退接和更平缓的外部曲线；仅接受质量改善且全部原有检查通过的结果。不声称核心整体随原路弯曲。
- 为现有九种已实现节点预览提供同一确认放置流程，不为未实现类型解除输入/布局限制。
- 地图左键仍只选端点，只有面板确认按钮能提交。保留暂停游戏要求；切模式/类型/设置/端点、取消、过期预览均不得应用。
- 确认前重新读取原始端点和每条完整路廊，用相同退接距离重新计算并严格比较当前源、消耗曲线/边版本、接点、保留尾段；原道路改变即拒绝并要求重新预览。
- 复用 NodePreviewPlacer 的全部只读准备检查并强化真实边/节点/预制体验证，确认检查不得向ECB写入删除或新建定义；不得重建一个未获游戏检查的新批次后直接Apply。
- 游戏原生 GetAllowApply、错误面板仍有最终决定权；等待至少一次临时道路检查就绪，不靠隐藏图标或打开Anarchy强制提交。
- 成功提交只一次，清理过期选择和预览状态，保留游戏原生批次行为。失败不得提前拆路，也不得把已失效候选留为可确认。
- 游戏原路改造属于玩家显式确认范围，继续显示消耗段数和尾段/接点范围；不声称自动备份存档或已验证实际通车。

## 实施所有权

1. 几何代理：EndpointRoundaboutFitter、RoundaboutSearch改进、独立弯路质量/预算/回退回归。先RED，再数值比较安全基准，全部净空和桥墩校验保留。
2. 放置代理：原生只读预检重构、纯快照/放置状态契约及测试、ToolSystem.Nodes与TryApply接线、UISystem节点状态/UI确认按钮及相关文案。先RED；确认只能使用当前已检查预览，原子批次复用现有Apply流程。
3. 协调者：复现与证据、审查关键提交路径、全量回归/构建/导出曲线、部署前游戏关闭检查和逐文件验证。
4. 必须独立复核几何与确认提交两部分。首轮实际放置、源路删除/保留尾段、连通性和保存重载由玩家在游戏中验收。
