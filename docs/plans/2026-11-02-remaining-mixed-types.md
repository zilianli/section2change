# 其余八类混合道路适配完善

> 执行方式：在当前autochange工作区逐项实现、记录RED→GREEN，最后进行一次独立复核；不提交或清理已有修改。

**目标：** 沿用已批准的共用转换方案，补齐其余八类在实际可用道路目录、短预留和分段弯路下的支持，推进到可部署测试包。版本保持0.0.1-beta。

**架构：** 原有核心／通用双向转换继续复用。将已实现的有界顺势平滑扩展到其它已支持类型；真实来源、外切点、整体128次预算和原生确认保持。发现类型差异时修复对应接线／可行性，不复制整套转换器。
