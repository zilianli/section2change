# Paradox Mods 发布与截图清单

发布配置：`src/InterchangeMod/Properties/PublishConfiguration.xml`（名称、简介、详细说明、截图、标签、GitHub 链接、更新日志都在里面）。
详细说明的英文 + 中文正文直接写在 `LongDescription` 里，改那里即可。

## 截图（游戏内截取后放到 `src/InterchangeMod/Properties/Screenshots/`）

文件名要和配置里的一致；PNG，建议 1920×1080，关掉游戏 UI（截图时只留需要的面板）。

| 文件名 | 内容 | 建议 |
|---|---|---|
| `overview.png` | 封面：一座完整的大型立交（定向或涡轮）全景 | 斜俯视、白天、周围有城市，最好看的一张 |
| `diamond.png` | 菱形或单点立交，放好后的样子 | 能看清匝道和被交道路的平交口 |
| `cloverleaf.png` | 苜蓿叶（可带集散车道） | 俯视，四个环道清楚 |
| `stack.png` | 定向式，多层高架 | 斜视角，体现层次 |
| `turbine.png` | 涡轮 | 俯视，风车形状清楚 |
| `retrofit.png` | 平改立：对准已有路口的蓝色预览（或改造前 / 改造后两张拼一张） | 体现“对准原路口一键升级” |
| `panel.png` | 工具面板：类型首页或设置页 + 结果区 | 中文或英文界面都可以 |

可选：`wye.png`（Y 型分向）、`curve.png`（弯道上的立交）、`expressway.png`（中式快速路节点）。增加时在配置里多加一行 `<Screenshot Value="Properties/Screenshots/xxx.png" />`。

GitHub README 也可以用同样的图：复制一份到 `docs/images/`，把 README 顶部注释掉的图片行打开。

## 缩略图

`src/InterchangeMod/Properties/Thumbnail.png`（已有）。Paradox Mods 列表里显示的就是它，想换时用 `overview.png` 裁成正方形（建议 512×512）。

## 发布步骤

1. 截图放好，确认 `ModVersion` 和 `ChangeLog` 已是本版本
2. 首次发布：用官方工具链的 Publish（PublishNewMod 发布配置），成功后把生成的 ModId 填进 `ModId`
3. 之后更新：用 PublishNewVersion 发布配置
