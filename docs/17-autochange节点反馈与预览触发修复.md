# autochange 节点反馈与预览触发修复

日期：2026-10-30。用户反馈八点选齐后点击了“生成预览”，未见提示；希望地图显示灰色可选节点和选中反馈。

## 已确认与尚待确认

旧版生成按钮与 nodeMessage 均在主滚动区域，用户截图中该区域已被端点列表占满；日志仅记录成功创建预览，不记录请求和失败。因此能确认诊断与交互反馈不足，尚不能据此断定用户当前道路能求出候选，也不能确定上次请求停在哪个阶段。不会把本轮 UI 测试记成原场景几何已修复。

## 修改

- 生成按钮与状态移出主滚动区域，固定于面板下方；点击后立即显示“已收到生成请求”。
- 有效端点新增至完整选择时自动尝试一次；修改参数后仍需主动重新生成，避免每帧重复求解。
- 日志覆盖按钮接收、进入求解、端点位置/切线/路型快照及失败提示；平面失败提供中文原因，包括不平直、空间不足和汇入重叠区。
- 鼠标周围 600 米内的可选开放端点显示灰色；悬停显示青色；选中后按方向 1/2/3/4 显示金/蓝/紫/绿圆点，并在旁边绘制对应数字。标记为只读 Overlay，不生成永久实体。选中点始终绘制，不受周围 256 点缓存上限影响。
- 附近节点使用游戏网络空间索引、30 帧/移动 100 米缓存刷新与数量限制；Overlay 和空间索引依赖同步完成后访问。
- 独立复核发现并修复：拒绝重复归组/满组操作误清已有预览；改参数、清分组后仍显示过期成功状态。

正式放置锁、真实沿路退接尚未开放等边界继续保留。空间不足的布局会明确拒绝，不通过忽略警告伪造成功预览。
