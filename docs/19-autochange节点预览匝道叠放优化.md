# 节点苜蓿叶：候选空间筛选

2026-10-30，分支 `autochange`，版本保持 `0.0.1-beta`。

## 原因与修复

原场景已经能够自动退接并显示预览，但日志和截图仍有单车道匝道与 Horizontal Pillar 8 重叠。原搜索仅以平面附件顺序与纵坡通过作为接受条件。宽主线的小空间场景中，满足坡度的第一个复合直连匝道仍会穿过相邻环道。新增左右行回归在旧实现上均失败，记录到同一高度附近的真实曲线包络交叉。

现在接受候选前使用实际主线宽度、匝道宽度与保守曲线细分净空检查：

- 不同匝道要求平面包络分离，避免通过抬高一条匝道解决路面交叉却仍让桥墩穿过另一条匝道。
- 不同主线以及主线与匝道检查宽度和竖向间距。本轮使用 8.5 米路面间距；这属于筛选余量，不等于所有游戏预制体的净空认证。
- 合法分合流只豁免规定的首末平坡曲线与正确主线的共节点路段，其余曲线继续检查。没有全局忽略相连道路之间的碰撞。
- 同一解析路径的曲线片段沿用既有直线、圆弧或单向复合转弯结构，不作自交认证。大角度斜交及后续更自由的路径需要另行补充。
- 冲突、无法确认和输入无效均不能接受；继续搜索半径、直连过渡长度和真实退接量。保留坡度上限和候选预算，面板显示空间拒绝数。

节点预览另外保存世界坐标曲线，在游戏错误变化时记录出错位置、按水平距离最近的候选曲线及错误实体来源。旧日志函数依赖旧模板路段，因此节点模式会提前返回，导致只有汇总没有定位。新日志使用 `[autochange-error]`、`[error-source]`；候选失效或重新生成时清空旧状态。最近曲线仅为定位线索，上下层投影相交时需结合实体来源判断。
