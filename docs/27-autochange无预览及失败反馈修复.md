# 定向/涡轮无预览及失败反馈修复

日期：2026-10-31，autochange / 0.0.1-beta。正式放置仍锁定，没有提交或发布。

## 复现与原因

截图底部实际已有NoCandidate文字，但它是小号普通文本，没有失败标题或醒目状态。日志`.artifacts/autochange/game-stack-turbine-no-preview.log`确认：两类型均为16%坡度、每臂500m退接，尝试21组截点后因方向3接路超过20°或反向退出，没有进入游戏临时道路生成，因此也没有游戏道路错误图标。

上轮生成层成功测试采用1000m，而面板默认500m。另一个占地问题是重复外部适配：旧内部模板带有两端40m引道和回原分隔带的S弯，新节点求解又独立生成完整外接路，这些重复段吃掉了有限接路空间。

## 修复

- 在旧输出仍保留路段名称时，只去除非Ramp的`-endA-/-endB-`外直线和`-in-/-out-`外S弯。所有匝道、编号主线路段、原桥墩规划切点及最外匝道之外至少20m余量保留。
- 外接路仍由真实截点独立生成，重新检查完整布局的坡度、20°方向、净空和支柱；不放宽安全约束或跳过报警。
- 节点退接默认上限改1000m，前后端保持一致。用户手动设500m仍尊重该范围，不静默超限。
- 后台新增明确失败标志，求解早退、无预览或异常都会显示固定红色“无法生成预览”卡片；参数、选择和新请求会清除旧状态。异常后的清理帧保留失败信息。
- 中文解释接路空间/方向、坡度、净空或桥墩约束，界面不再倾倒内部英文曲线诊断，完整信息仍在日志。
- 失败且上限不足1000m时显示“上限改为1000米并重试”，点击后先改上限再提交生成请求。正文加大并可滚动，状态区置于设置滚动区外。
