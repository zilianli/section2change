# autochange 定向与涡轮节点预览

日期：2026-10-30。分支autochange，版本0.0.1-beta。苜蓿叶已由用户反馈通过，本轮推进定向和涡轮，正式放置仍锁定，没有提交或发布。

## 新增范围

- 节点模式新增定向式和涡轮，沿用点选反馈、真实原路退接及临时预览。定向在节点面板提供右出右进、左出左进；两条道路分别匹配精确减去匝道车道数的道路，左出左进沿用旧版保持外侧直行边缘的平衡规则。
- 按所选道路的宽度、分隔带、交角、世界高程及交通侧，复用section2change内部匝道算法重新求解。只做世界参考系刚性变换或镜像，不缩放成品。LHT及两个道路家族高低层交换保留原臂编号和流向。
- 沿原路真实曲线有界退接，独立生成接路段，精确保留截点坐标、高程、切线、Prefab和节点版本绑定；端部方向适配不超过20°。所有新增接路经过完整检查。
- 类型无关的三维净空检查允许安全上下穿越，拒绝未分层或净空不足的交叉。只有精确3D共同节点的规定终端曲线允许局部合流，不能按相同来源/类型跳过独立路径。
- 全局复核节点、自动切分和中部支柱，full/reduced/ramp逐段使用实际Prefab规则，缺失要求的元数据会拒绝。实际柱宽采用目录中最大水平尺寸的保守包络，仍需游戏验证方向和地形。

当前要求四方向各一进一出的双幅道路。同一道路家族的两端和两幅必须同款、同宽、同车道；两个家族之间允许不同断面。双向单幅、单双幅混合转换、同家族不对称断面尚未接入新几何，会明确拒绝。三向及平交类继续后续阶段。

## 有界重求

旧版定向左出左进个别曲线会略超请求坡度（例如请求12%，采样可到12.596%）。新核心严格认证每条输出，必要时收紧内部求解坡度重新计算，不把旧容差当验收标准。

新支柱复核也抓出旧固定节点压到其他匝道的方案。通过侧隙、较缓坡度或加宽内部中央分隔带重求布局，不跳过检查。定向最多11组参数备选，涡轮最多6组；每组内部最多4次严格坡度重求。真实退接有独立预算，上限0～1000m/臂，遇路口/尽头停止。

日志混合高程案例中，定向右出右进在内部侧隙5m通过；左出左进增加24m内部中央分隔带后通过，外部仍平滑接回实际分隔带和端点；涡轮有案例增加1m侧隙通过。这些是个例，不保证所有输入可解或全局最紧凑。

## 游戏回测

1. 复制存档并暂停；四方向双幅道路，建议每幅4车道、单车道匝道，退接上限1000m、层差自动。
2. 定向右出右进：检查8条匝道汇入汇出、跨层净空、桥墩和主路减车道段。
3. 定向左出左进：切换后重新生成，检查分隔带侧接口、两条左转接口之间减车道、外侧直行边缘及加宽后平滑接回原道路。
4. 涡轮：检查四条左转绕行方向、风车交叉的分层净空和弧线内桥墩，无叠放/形状报警。
5. 比较16%与27%/30%，先同高，再混合高程和弯曲端点。固定预览停留5秒，记录报警、坡度和截图，日志可对应位置。
6. 切换类型后重新选该类型端点；调参数后旧预览失效，再点生成；退出清除临时道路。

正式放置、真实车道连接、交通模拟、地形及全部桥墩外观尚未验证。游戏通过后继续喇叭形、定向T、半定向T和Y型，再推进平交及环岛类。
