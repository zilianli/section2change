## 标题 / 简介

- **名称**：section2change
- **简介（英）**：Turn a junction into a complete interchange in one placement (平改立)
- **标签**：Code Mod

## 详细说明

见 PublishConfiguration.xml 的 `LongDescription`（英文 + 中文：13 种类型、功能、三步用法、注意事项、反馈方式）。

## 本版更新（ChangeLog）

**1.0.7-beta**
- Lane balance for stack left-exit, cloverleaf divided cross roads, trumpet branch, partial cloverleaf and roundabout mains
- Ramps are edge-aligned where they join or leave the road

**1.0.5-beta**
- Ramps keep at least 3 m (default 4 m) from the main road; elevated diverges leave on an 80 m arc
- Two-way diamond mains split into carriageways; turbine / stack keep the full game clearance
- Wye matching is steadier and legs reconnect; interchanges on slopes follow one reference grade
- Usage guide reordered; placement cannot be undone

## 发布步骤

1. 游戏关闭，`cd src/InterchangeMod && dotnet build -c Release` 确认能构建
2. 首次发布：发布配置选 **PublishNewMod**（Visual Studio 右键项目 → 发布，或 `dotnet publish /p:PublishProfile=PublishNewMod`），登录 Paradox 账号
3. 成功后把返回的 ModId 填进 PublishConfiguration.xml 的 `ModId` 并提交
4. 以后更新：改 `ModVersion`、`ChangeLog`，用 **PublishNewVersion**
5. GitHub：`gh release create v1.0.7-beta --notes-file docs/07-发布说明-1.0.7.md`（可附 Release 构建的 zip）
