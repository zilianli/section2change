# 井字弯路接入与汇入曲率优化

2026-11-01，autochange，0.0.1-beta。修复已生成预览在弯路接回位置触发原生叠放的问题，并改善直行/集散道分合流曲率。正式放置保持锁定，不提交、推送或发布。

## 原因与回放

本轮02:35日志保存于 `.artifacts/autochange/game-grid-curved-failure.log`。生成器成功生成138段道路，退接275/250/200/325米；随后原生OverlapExisting指向方向1的两条新建20米全宽道路，源和目标均为Create，不是旧路遗漏拆除。

日志的8个节点、三维位置和切线与既有 `curved-no-preview-20261031.json` 吻合，因此可复用该真实曲线资源。资源仅保存前500米走廊，本轮游戏可退接约784～960米，不将旧资源称为完整1000米现场采集。未记录的桥墩包络继续采用4米保守假设，不能替代原生检查。

修复前回放精确重现相同退接向量和冲突曲线，两条20米宽道路中心线采样最小距离20.6738米：原8米中央间隔被两条独立接路曲线挤至约0.67米。原检查只认证20米路面宽度，未保留节点形状所需的间隔余量。核心横移曲线虽相切，分合流边界仍有约0.0784/m的平面曲率突变。

## 变化

- 井字候选按实际退接后两端的连线求道路家族和中心；保留80～100°家族交角，真实接点与原路切线由外部接路保留。割线求解不再依赖切线参考是否能求交。
- 对相对的两条全宽道路另做连续曲线间距认证，保留 `min(4米, 原中央间隔/2)` 的余量。原20米道路、8米中央间隔要求中心线至少24米。按真实断面区分两条道路家族，不给内部合法分合流增加这一缓冲。
- 在原128次完整候选、64次核心工厂、256次核心试验预算内增补接路控制柄选择；不通过忽略原生警告或取消碰撞来强行生成。
- 直行与集散道横移使用三段连续缓和曲线，两端平面曲率为零，内部接缝曲率连续。横移长度同时考虑直行和集散道的最大绝对位移，包括宽中央间隔；曲率目标依据真实道路宽度计算。
- 直行横移与爬坡重叠求解，第一缓和段和末20米使用三次纵向缓和，接点处纵向曲率也缓到零，避免将完整爬坡与完整横移简单相加而扩大布局。原8%坡度下500米以内的核心范围回归仍通过。
- 仍使用真实Prefab跨距与中间桥墩规则。短跨距强制增加节点时，净空或桥墩检查可原子拒绝该候选；没有增加非法跨度、取消真实桥墩或放宽坡度。
