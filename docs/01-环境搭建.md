# 阶段 0：环境搭建（新手版）

目标：做出一个 Hello World mod，能在游戏日志里看到它被加载。

## 1. 已检测到的工具

| 工具 | 状态 |
|---|---|
| .NET SDK 8.0 | ✅ 已安装 |
| Node.js 22 | ✅ 已安装（UI 模块要用） |
| Git | ✅ 已安装 |
| Visual Studio 2022 | ❓ 请自行确认 |

## 2. 安装 Visual Studio 2022 Community（免费）

1. 下载：https://visualstudio.microsoft.com/zh-hans/vs/community/
2. 安装时勾选工作负载 **「.NET 桌面开发」**
3. 另外在「单个组件」里确认勾选了 **.NET Framework 4.8 目标包** 和 **.NET Standard 2.1** 相关组件

> 也可以用 JetBrains Rider，但官方模板主要面向 VS，新手建议用 VS。

## 3. 在游戏里安装官方 Modding 工具链

1. 启动 Cities: Skylines II
2. 进入 **选项（Options）→ Modding**
3. 点击安装工具链依赖（Install / Download dependencies），等待全部显示为已安装
4. 工具链会设置一组以 `CSII_` 开头的环境变量（模板靠它找到游戏 DLL）
5. **安装完成后重启电脑**（或至少重启 VS），让环境变量生效

验证环境变量（PowerShell）：

```powershell
Get-ChildItem Env: | Where-Object Name -like 'CSII_*'
```

能看到若干条 `CSII_...` 就说明成功。

## 4. 用模板创建主 mod 工程

1. 打开 VS2022 →「创建新项目」→ 搜索 **Cities: Skylines II** → 选择 mod 模板
2. 项目名填 `InterchangeMod`，位置选 `F:\claudecode\Cities Mod\src`
3. 不要勾选「将解决方案和项目放在同一目录」
4. 创建后右键解决方案 →「添加 → 现有项目」，把它加入仓库根目录的 `InterchangeMod.sln`
5. 右键 `InterchangeMod` 项目 →「添加 → 项目引用」→ 勾选 `InterchangeMod.Generation`

> 如果搜不到模板：确认第 3 步完成并重启过 VS。仍然不行请查阅 Paradox 官方 CS2 Modding Wiki 中 “Toolchain” 页面。

## 5. Hello World

模板生成的 `Mod.cs` 里有一个 `OnLoad` 方法，确认里面有类似这样的日志语句：

```csharp
log.Info(nameof(OnLoad));
```

在它下面加一行：

```csharp
log.Info("Interchange Generator 已加载！");
```

## 6. 编译并在游戏中验证

1. VS 顶部选 **Release**（或 Debug），按 `Ctrl+Shift+B` 编译
2. 模板会自动把 mod 复制到本地 Mods 目录（`%USERPROFILE%\AppData\LocalLow\Colossal Order\Cities Skylines II\Mods\`）
3. 启动游戏 → 内容管理器中确认 mod 已启用 → 进入任意存档
4. 打开日志目录 `%USERPROFILE%\AppData\LocalLow\Colossal Order\Cities Skylines II\Logs\`，
   找到以 `InterchangeMod` 命名的 `.log` 文件，搜索 “已加载”

看到这行字，阶段 0 就完成了 🎉

## 7. 推荐顺便装的工具

- **ILSpy**（https://github.com/icsharpcode/ILSpy）：打开游戏目录 `Cities2_Data\Managed\Game.dll`，
  搜索 `NetToolSystem`、`NetCourse`、`CreationDefinition`，阶段 1 要照着它造路
- 下载 **Road Builder**、**Anarchy** 等开源 mod 的源码当参考

## 常见问题

| 现象 | 处理 |
|---|---|
| 编译报找不到 `Game.dll` / `Colossal.*` | `CSII_` 环境变量没生效，重启电脑 |
| 游戏里看不到 mod | 检查 Mods 目录下是否有 `InterchangeMod` 文件夹；内容管理器里是否启用 |
| 日志没有输出 | 确认进的是存档/新地图，而不是只停在主菜单 |
| 编译报 `MSB3073`，提示缺少 `Microsoft.NETCore.App 6.0.0` | 工具链的 `ModPostProcessor.exe` 需要 **.NET 6 运行时**。安装 .NET 6 Desktop/Runtime（x64）后重新编译。临时办法：命令行用 `DOTNET_ROLL_FORWARD=Major dotnet build` 让它跑在 .NET 8 上 |
| 找不到 VS 模板 | 命令行也能建：`dotnet new csiimod -n InterchangeMod -o src/InterchangeMod -I -In` |
