# autochange Y型节点预览与后续范围

2026-10-31；`autochange`；版本维持 `0.0.1-beta`。用户已确认上一轮三向主线识别修复通过；本轮接入Y型节点预览，不提交或发布，正式放置继续锁定。

## Y型实现

三条臂无主次，每方向选一进一出的双幅开放端点，共六点。支持相邻交角90°～150°，保留原始分组编号，不套用T型的方向1/3主线规则。基于section2change既有WyeTemplate按实际断面、角度、交通侧与世界高程重新求解，通过刚性定位与左右交通镜像生成，未缩放资产。

首轮要求三条臂的每幅车道数相同且为偶数，每条匝道为其一半：2→1+1、4→2+2、6→3+3已测试。自动在目录选择精确半车道匝道，不会静默沿用上一个类型的单车道匝道。同一臂两幅须同款同宽同车道；三臂之间可不同宽度或Prefab。奇数、不等车道及单双幅转换明确拒绝，不宣称已支持。

内部三条臂在同一基层，左转飞越层在上层。基层取六个端点平均高程加偏移；层差0时至少10米，实际道路结构包络要求更大时自动提高并留余量。显式不足的层差给出所需米数。原路各端高程、真实切线与节点身份均保留，由附加接路消化高差；不采用T型保留主支路高差及两层下穿开关。

输出为六条有向非掉头匝道、六条进出道路链与六个外部端口。验证精确共享节点、六种必要有向动作、不引入掉头、真实Prefab宽度、严格纵坡上限、水平弯曲、整网道路净空和桥墩。最大坡度仍为玩家设置且不超过30%；超过18%的无碰撞辅助提示继续有效，提示不自动启用Anarchy，也不隐藏游戏报警。

## 净空复核修正

独立复核发现初稿只按固定8.5米认证，未消化自定义道路的竖向结构范围。本轮补充先失败后通过的回归：具有20米净空顶和-20米结构底的断面至少需要40米层差，不能接受10米跨越。核心、自动层高和最终附加接路使用同一实际包络要求；无效范围拒绝。反向专用匝道也明确拒绝。

## 搜索与测试结果

沿真实原路获取独立三臂切点，按该组切点重求核心，再连接六端口。每臂0～1000米、遇原路路口/尽头停止；候选受统一次数限制，失败不保留部分网络。支持的交通侧镜像、不同分组顺序、混合端部高程和弯曲接路均有生成层测试。

## 游戏复测步骤

1. 选择Y型和“点选节点”，使用相邻约120°的三条双幅道路；首轮建议三臂均用每幅4车道。
2. 每方向选择一进一出，共六端点；保持基层偏移0、层差0自动、退接上限1000米。三条臂无主次，不会因选择支路顺序而重编号。
3. 先用16%生成预览，检查三处汇入/驶出、桥墩、净空与游戏原生报警；随后按需比较8%和30%的占地及衔接。
4. 追加混合端部高程和缓弯接路；截图保留面板、警告及整个布局，便于从日志对应场景。正式放置仍锁定。
