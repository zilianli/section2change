# autochange v0.0.1beta 首轮游戏测试

2026-10-30。当前安装包是**点选和临时预览测试版**，正式放置锁定。尚未实现真实原路延伸、完整净空/桥墩检查及其他类型几何，不能把它当作完整节点建造版本。

## 已验证的交付

- 完整生成层测试 1279 项通过，失败与跳过均为零；新增状态选择及独立端点吸附测试通过。
- C# Release 主 Mod、UI webpack 构建及 UI TypeScript 检查通过。构建仍有既存 StackTemplate 可空警告与 Sass 旧 API 弃用警告。
- 本地 Edge/Playwright 以模拟游戏绑定验证点选菜单、分组按钮、生成预览触发、选点列表、自动/手动切换和确认放置按钮隐藏，无页面运行错误。模拟绑定不能证明游戏输入、临时道路和网格表现。
- 独立静态复核发现并修复：短支路误吸附路口；贯通两端不同道路宽度导致规划/预览不一致。正式放置在 UI、节点模式更新和 TryApply 三处阻止。
- 游戏关闭时部署至本机 Mods/InterchangeMod；26 个安装文件与暂存包 SHA256 一致，mod.json 为 `0.0.1-beta`。清单 `.artifacts/autochange/deployment-node-preview-manifest.json`。
- 部署前的 1.0.8.1-beta 保存在 `.artifacts/autochange/installed-before-node-preview`，未提交、推送或发布。

## 玩家测试顺序

1. 使用复制存档并暂停。打开苜蓿叶，点击“点选节点”，确认自动/手动不再高亮；出现四个方向分组。
2. 选四条朝向中心空白区域、各自一进一出的双幅平直道路，共八个开放端点。按顺时针归组，方向 1/3 对向、2/4 对向。每条贯通车流两端道路预制体须一致。初测建议中心到端点各约 250–350 米，端点高度接近，层差先用默认 10 米。这里是测试建议，不保证这些尺寸都能求出候选。
3. 点击某个方向按钮，再到地图靠近该方向两条道路的尽头点击（32 米以内）。检查列表里的驶入/驶出、道路名和海拔。重复点击已选点应取消；右键或“清空”只清当前方向。特别试一次长约 100 米、从路口拉出的短支路开放端点，确认能选到尽头。
4. 选齐后点击“生成预览”。最大坡度可设 16% 起测，无候选时可调整到 30%。查看临时道路是否出现、两层是否按实际海拔布局，以及游戏是否给出叠放、坡度或净空警告。未找到候选会显示失败原因和本轮范围；不会无限搜索。
5. 修改坡度/高度/分组后，旧预览应立即清掉；再次点生成才重建。切换自动/手动、返回首页、关闭工具，观察临时道路是否清理。确认节点模式不能正式放置；即使打开 Anarchy 也不能放置。
6. 负例：少选端点、两幅同为驶入、把同一点放到不同方向、点击非开放路口、选双向/混合道路、切到 T 型/Y 型。应得到明确输入诊断或“几何未接入”的提示，不应崩溃。三向类型应显示三个方向。

## 本轮反馈内容

告知“点选是否准确 / 八点是否识别 / 预览能否出现 / 模式切换是否清理”四项结果。失败时记录立交类型、道路名称、面板提示和大致时间；预览叠放可以截图保留，不必正式放置。

实际游戏输入、Temp 清理、精确接路、桥墩、道路网格与车辆行为仍未由本轮离线测试证明。后续按这些测试反馈继续完成正式放置闭环，再扩展其他立交类型。
