## 可以直接复用的部分（来自喇叭形）

- 圆弧路径工具：与两条直线都相切的复合圆弧（`Path.Fillet` / `Path.Turn`），任意转角（含 270° 环道），按长度分段、两头并行重叠段保持所接道路高度、重叠段之外再多保持 15 米。
- 环道半径自动：`RadiusSearch` 找能放下的最小半径；面板“自动 / 手动”。
- 接高架道路的一头用 ≤ 80 米的小半径圆弧（重叠段短于游戏切分高架路段的长度，立柱不落在所接道路上）。
- 双向道路拆成双幅（两幅放得进双向道路宽度、至少 2 米分隔带），外端边缘对齐接回。
- 车道平衡：匝道平行接入减车道后的主线外侧，边缘对齐。
- 交角 35°–145°，斜交时道路沿真实方向，圆弧转角随交角变化；超过 45°–135° 提示开启无碰撞。
- 路口匹配、十字路口 / 立体交叉、原路口改造（拆除 + 接回）、基层跟随已有道路、错误位置日志。

## 5a 全苜蓿叶（`CloverleafTemplate`，快速路 × 快速路）

```
            │ ║
      ╭───╮ │ ║ ╭───╮
      │ ○ ╰─┤ ║─╯ ○ │        ○ = 环道（左转，270°），四个象限各一条
  ════╪═════╪═╬═════╪════    主线（双幅）
  ════╪═════╪═╬═════╪════
      │ ○ ╭─┤ ║─╮ ○ │        外侧直连匝道（右转），四个象限各一条，绕在环道外侧
      ╰───╯ │ ║ ╰───╯
            │ ║  被交道路（双幅；双向道路在立交内拆成双幅）
```

- 两条道路都是双幅，一条从另一条上面跨过（面板“上层道路”）；只有这一座桥。
- 每个象限：一条环道（左转 270°，升降一层）+ 一条外侧直连匝道（右转，同时与两条路相切，升降一层）。
- 每一幅上的顺序（右侧通行）：外侧匝道驶出 → 本象限环道汇入 → 过桥 → 下一象限环道驶出 → 外侧匝道汇入。
  桥两侧环道汇入和驶出之间是**交织段**（苜蓿叶的固有问题），见下面的问题 1。
- 车道平衡：外侧匝道驶出后减车道、环道汇入后恢复；环道驶出后减车道、外侧匝道汇入后恢复（交织段保持全宽）。
- 右转匝道两种形式（面板可选，默认外侧大弧线）：
  - **外侧大弧线**：见下一条；
  - **贴环道**：右转匝道贴着环道外侧走，与环道相邻的那段两者合成一条双向匝道（每方向车道数同匝道，中心线在环道外侧 W/4，环道走内半幅、右转匝道走外半幅，右侧通行时方向正好对上），两端边缘对齐分开；右转匝道两头是与环道同向转的小半径连接弯（反向曲线），高度跟随环道在分开点的高度，占地小得多。
- 环道半径自动 / 手动。外侧匝道两头用小半径（≤ 80 米）圆弧，中间是大半径、近乎直线的斜段，自动取能绕过环道外侧的最紧凑的那条（单一大圆弧要绕过环道，半径约为环道的 6 倍以上，占地大得多）。
- 立柱：上层道路跨越段避开下层道路（复用立柱规划）；环道和外侧匝道接高架道路的一头用小半径圆弧。

## 5b 部分苜蓿叶 ParClo（`PartialCloverleafTemplate`，快速路 × 普通道路）

- 被交道路是普通道路（双向或双幅），在地面与匝道形成两个平交路口（各一组信号灯，或让行）。
- 只有两个象限有环道，四条匝道（两条环道 + 两条斜向直连匝道），去掉了交织段。
- 两种常见布置：
  - **A2**：环道在“驶入被交道路之前”的象限（主线驶出走环道，驶入走直连匝道）；
  - **B2**：环道在“驶离被交道路之后”的象限（主线驶入走环道）。
- 平交口离桥的距离、匝道与被交道路的夹角按游戏内节点不重叠来定。

## 实现顺序

1. **5a-1**：圆弧路径工具从喇叭形里提出来共用；全苜蓿叶（主线交织），环道 / 外侧匝道半径自动或手动，车道平衡，斜交，改造与接回。
2. **5a-2**：集散车道（C-D）选项：主线每幅外侧一条平行单行道路（用匝道道路，间距 max(匝道间距, 2 米)），两头用两段反向圆弧的 S 形与主线相接（主线高架时半径 80 米、整段不设中间节点）；四条匝道都接在集散车道上，主线在 S 形驶出与汇入之间减车道。被交道路跨越时立柱避开主线连同集散车道。
3. **5b**：ParClo A2 / B2。
