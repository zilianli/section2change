# 节点苜蓿叶混合高度与弯曲接路

2026-10-30，`autochange`，维持 `0.0.1-beta`，正式放置仍锁定。

## 两组反馈与原因

用户已验证上一包外观平滑、无叠放，随后报告混合高程和同高弯路均无法预览。对应日志约 14:54、14:57，两者均为 `NonStraightApproach`，纵断面未执行、空间拒绝为零；不是已证明的“高度过大”。旧候选强制要求每条贯通车流两端在切线误差 0.05 米内共线。混合高度场景端部存在约 3° 偏差；同高弯路端部约 14°。

## 实现

新设计允许端部与对臂连线不超过 15° 的方向偏差；主体仍依据所选端点重新求解。主线首末接路段改为真实 Bézier，起终切线分别匹配原路与主体，随后生成独立世界高度剖面。保留每个切回点的真实位置、高程和纵向切线，坡度仍按指定值认证，最高 30%。超过方向范围的输入继续拒绝，无 design 的旧纯几何 API 仍保持 0.05 米严格约束。

空间检查仍检查实际曲线和实际宽度。首末连接段在主体轴上的投影单调，不允许掉头回折；同一解析路径的自交免检依赖该前提。分合流豁免依然局限于规定的平坡匝道段与正确逻辑节点，不扩大到整条匝道。

自动层高沿用两组道路已有平均高度差。但混合端点可能让上层平均值落在地形以上 4–8.5 米的实心路堤区。本轮在自动高差、零偏移时，按中心地形将两层一起抬高至上层达到 8.5 米桥梁阈值；外部端点不抬高，以连接段过渡。手动偏移或手动层高差不被自动覆盖。此处仅是中心地形启发式，不代表整座立交的地形/桥墩认证。

新弯路样例在 16% 下需要更广的圆弧搜索，默认候选预算从 2048 提高至 6144，仍有明确上限；27% 和混合高度样例在较少候选内可解。半径无关的方向失败每个退接量只查一次，避免把同一错误重复数千次。面板显示 15° 适配边界，日志记录两层世界高度、中心地形、自动抬升量与轴线拟合误差。

## 验证及边界

- 原日志的两组舍入端点、高度、切线在旧算法上均复现平面拒绝。
- 10 个新增实例覆盖 16% / 27%、层位方向互换、合成直线/弯曲原路延续、外接点精确三维切线、过大偏角拒绝、旧严格 API、自动层高/手动设置及实际道路包络冲突拒绝。
- 600 米原路延续属于合成测试数据，没有将未读取的真实原路曲线冒充为复现。部分弯路在 16% 下仍可能因主线包络冲突而拒绝；提高坡度也不能绕过空间检查，不宣称任意弯路都可求解。
- 独立只读复核未确认重大问题，并独立数值复现同高日志端点加合成直线延续：16% 下 4456 个候选、四臂各退接 475 米、68 段，端点切线点积最小约 0.999999909。单次较复杂样例约数秒，不属于实时逐帧求解。
