# 弯道适配方案（阶段 7a）

决定（2026-10-26）：
- 只考虑直线和简单曲线（单段圆弧），S 形不做。
- 两条路（主线、被交道路）都可以是弯道。
- 方式：立交仍按直线生成，再**整体沿弧线弯曲**（所有立交类型一次支持），不在每个模板里单独处理弧线主线。
- 弯道求解可能更慢：面板要提示玩家。

## 1. 读出弯道半径

- 路口匹配（`JunctionReader` / `JunctionMatcher`）现在只读每条臂在路口处的切线方向。另外读每条道路的**带符号曲率** κ = 1 / R：
  沿离开路口的路段采样（路口处、约 40 米、约 80 米三点）定圆，主线两条臂、被交道路两条臂各一个；同一条路两侧的曲率按同一前进方向折算后取平均。
- 两侧弯向相反（S 形）或差别很大时按直线处理（κ = 0），面板说明“S 形弯道不适配”。
- 半径大于约 3000 米按直线处理；小于下限（先定 250 米，按立交大小再调）时报错“弯道半径太小”。
- 只对准一条道路（在路上放置，不是路口）时用鼠标所在路段的曲率；立体交叉（虚拟交汇点）两条路各取各的路段。

## 2. 弯曲变换（生成层 `CurveWarp`，纯 C#、可单元测试）

立交局部坐标：中心 O，主线方向 ê_m，被交道路方向 ê_c（与主线成交角 θ），斜坐标 p = O + a·ê_m + b·ê_c。

- 弧线：A_m(a) 是主线圆弧上离 O 弧长 a 的点，转角 φ_m(a) = κ_m·a；被交道路同理 A_c(b)、φ_c(b)。
- 沿主线弯：W_M(p) = A_m(a) + Rot(φ_m(a))·(b·ê_c)。主线中心线和与它平行的各幅（双幅、匝道并行段）都**精确**落在平行弧上；被交道路的两幅会张开（不用它）。
- 沿被交道路弯：W_C(p) = A_c(b) + Rot(φ_c(b))·(a·ê_m)。对被交道路精确，主线两幅会张开（不用它）。
- 混合：W(p) = (1 − t)·W_M(p) + t·W_C(p)，t = smoothstep(0.35, 0.65, |b| / (|a| + |b|))——离主线近（|b| 小）用 W_M，离被交道路近（|a| 小）用 W_C（主线中心线上 t = 0、被交道路中心线上 t = 1，所以各自只需对自己那条路精确）。两条路的中心线和各自平行的各幅都精确；中心附近两者只差几十厘米；象限里的匝道被平滑拉伸 / 压缩（两条路都弯时这是必然的：两个弯道之间的距离和直线时不同）。窗口再宽（0.15–0.85）过渡更缓，但离中心 60 米内的平行各幅不再精确，不用。
- 只有一条路弯时（另一条 κ = 0）同一公式退化为：弯的那条精确、直的那条保持直线不张开。
- 路段：端点和节点按 W 变换（同一个局部点得到同一个结果，节点照样合并）；两头切线方向按端点处的雅可比矩阵（数值差分）变换，前后路段在共用节点处仍相切；两个控制柄长度按最小二乘贴合逐点弯曲的原曲线。普通路段偏差在厘米级；从主线一直走到被交道路、穿过整个过渡区的长匝道（如菱形 140 米的匝道）与逐点弯曲相差 1 米多——那里的“理想形状”本来就不唯一，弯曲后的坡度、间距另行检查。
- 高度（离地高度 Y）不变。

## 3. 弯曲后的检查与重算（会更慢的原因）

- 弯道内侧的匝道被压短，坡度变陡（压缩比约 (R − 横距) / R）；外侧被拉长。
- 弯曲后逐段检查坡度；超过上限时把求解用的最大坡度按超出比例收紧，重新生成再弯曲，最多重试 2–3 次，仍不行就报错“弯道上放不下：请加大最大坡度或换更大的弯道”。
- 弯曲后再跑一遍几何检查（`InterchangeLayout.ValidateGeometry`）；匝道间距因压缩不足时同样报错。
- 结果按参数缓存（曲率按 1/1000 取整进缓存键），同一处只算一次。

## 4. 工具和面板

- 立交范围（拆除原有道路的凸包）、臂端接回都用弯曲后的路段，臂端正好落在原有弯道上。
- 面板：对准弯道时显示主线 / 被交道路半径，并提示“弯道上的立交整体顺着弯道弯曲，求解较慢，坡度超限会自动收紧重算；放置前请仔细检查预览”。
- 两步放置（已做）：左键只固定预览，面板确认才放置——弯道求解慢时不会因为鼠标一动就重算。

## 5. 实现顺序

1. `CurveWarp` + 测试：κ = 0 时不变；主线 / 被交道路中心线和各幅落在弧上；节点仍精确相等；控制点偏差小。
2. 坡度检查与重算 + 测试：R = 400 米左右的弯道上，菱形、苜蓿叶、定向式、涡轮等能放下且坡度不超限。
3. 读曲率（`JunctionReader` / `JunctionMatcher`），面板显示半径与提示。
4. 工具接入：生成后弯曲、范围与接回用弯曲后的路段；游戏内验证。
