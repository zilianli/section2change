# autochange 三向主线自动识别修复

2026-10-31；分支 `autochange`；版本保持 `0.0.1-beta`。本轮处理玩家反馈的平直道路喇叭、定向T无法预览；不增加新立交类型。

## 原因与证据

原实现规定方向1/3为主线、方向2为支路。玩家从支路开始选择，实际相对的主线是方向2/3。六个端点都有效，但错误分组使曲线场景被计算成24°支路夹角；平直场景也被计算成约44°，并出现错误参考系下的桥墩冲突。单纯增加1000米退接上限不能纠正这个参考系。

本次保留日志中的两套真实端点、方向、道路曲线和实体快照，保存为测试资源 `three-way-flat-failure-20261031.json`。原路高程约488.632米、地形约478.632米；平直场景的支路约500.42米，不能当成所有道路同高。两套场景乘以三种T型，修复前六项预览回放均失败，两项分组断言也失败。

## 修复行为

- 三种T型从任一条臂开始分组，输入请求会识别明确相对的贯通主线，规范为方向1/3；支路规范为方向2。
- 分组只重排原始快照，不修改实体身份、位置、切线、车流方向、道路宽度和车道数；每臂退接上限随对应道路一起重排。
- 自动预览触发使用同一份识别规则，支路与主线断面不同时也不会因错误的对向车道比较而漏触发。
- 选中节点颜色、方向编号及当前活动分组同步调整。面板说明已更新。日志新增原分组到规范分组的对应关系。
- 至少140°的明确相对方向、相对其他组合至少20°的优势以及正确的向外几何朝向，才自动重排。不能明确判断的Y形输入保留原分组；不依据道路宽度或车道数猜主线。
- 四向立交和Y型输入规则保持原有契约；坡度、接路、净空、桥墩检查继续执行；正式放置仍锁定。

- 输入和回放测试95项通过；三向核心、接路等针对性回归176项通过。覆盖六种分组排列、左右侧通行输入、不同主支路断面、独立退接上限及不可变原始快照。

## 游戏复测

1. 原场景仍可从支路开始，三条臂分别选一进一出六个端点。识别后应看到主线变为金色/紫色、支路变为蓝色，选点不丢失。
2. 保持16%、1000米上限、基层偏移0、层差自动，分别生成喇叭、定向T、半定向T预览。
3. 观察是否有预览、汇入平滑度及游戏原生叠放/形状警告；喇叭的出口/入口环道切换可追加复测。
4. 本轮只验证预览，正式放置仍锁定；两层T在高架主线上继续显示明确的下穿限制。
