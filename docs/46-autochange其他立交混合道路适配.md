# autochange：其余八类立交混合道路适配

日期：2026-11-03。分支autochange，版本保持0.0.1-beta。

## 本轮范围

环岛之外，完善苜蓿叶、定向、涡轮、喇叭、定向T、半定向T、Y、井字。节点模式沿用现有确认放置流程。部分苜蓿叶继续跳过，梅花维持移除；菱形、单点和中式快速路不新增节点支持。

| 类型 | 本轮覆盖的主要变体 | 输入形式 |
| --- | --- | --- |
| 苜蓿叶 | 普通、贴环道、交换上下层 | 四向全双向、双幅与双向混用 |
| 定向 | 右出右进、左出左进、交换上下层 | 四向全双向、混合 |
| 涡轮 | 默认、交换上下层 | 四向全双向、混合 |
| 喇叭 | 环道驶出主线／驶入主线 | 三向全双向、混合 |
| 定向T | 三层、地面主线两层 | 三向全双向、混合 |
| 半定向T | 三层、地面主线两层 | 三向全双向、混合 |
| Y | 六种有向连接 | 三向全双向、混合；每幅偶数车道 |
| 井字 | 四层集散结构 | 四向全双向、混合；每方向至少3车道 |

“双向”指一个道路实体内具有对称双向车道；“双幅”指一进一出两个单向实体。高速与普通街道按真实目录查找准确车道数的单向断面，自动选择沿用普通道路过滤。相对贯通方向仍需匹配核心要求的同款同宽单向断面；不对不对称车道数、公交专用或缺少对应断面的组合静默减车道。

## 实现变化

- 八类共用已实现的顺势接路平滑：改善外部双向分合流的曲率，不移动已选中的真实外切点、不替换内部已认证核心。新外观方案必须更平顺且重新通过实际全网检查，否则保留原方案。
- 苜蓿叶有限搜索按真实宽度、纵坡和过桥平段预估优先种子，每个种子先搜索有效退接窗口；长匝道阶段保留预算，低坡度不再在短半径组合中耗尽全部次数。既有局部缩短优化继续保留。
- 井字在原六种布局后增加较晚结束第一集散道课程的备选，解决普通街道减车道后道路物理宽度仍很大的分合流冲突。横向过渡仍保持曲率连续，真实桥跨和最小半径检查不放宽。
- 定向／涡轮的混合路径提前检查完整核心和接路最小半径，避免较差的拟合方案覆盖可行种子。原始参考没有候选时，允许对有限组真实退接快照重建弯曲核心；同组切点同时用于核心参考和接路。
- 小于12%坡度且原双向道路有纵坡的定向，可让数学双幅廊道与真实转换段共同分担高差，并联合求解转换根节点纵坡。数学廊道只是假设；真实道路的高度、切线、实体身份和切割均从原始来源重算。

核心、真实转换、外观改善共享128次完整候选预算；退接参考回退另有限制核心枚举次数。保留完整实际道路的宽度、坡度、最小半径、净空与桥墩检查；不自动开启无碰撞，不压制原生错误。较大坡度与紧凑斜交的现有无碰撞提示保留。

公开求解入口保留原签名，新诊断和混合专用选项放在内部实现。原双幅调用不启用新增的混合专用开关。

## 玩家测试顺序

先用16%及每臂1000米上限，分别保留一处全双向和一处双向／双幅混合测试场景：

1. 苜蓿叶普通／贴环道，定向两种出入口，涡轮：先直路，再弯路和混合高度。
2. 喇叭两种环道，定向T和半定向T：三个方向选点。两层T须地面主线，不能要求高架主线向下穿越地形。
3. Y：三个方向、每方向偶数车道；井字：四个方向、每方向至少3车道。
4. 抽测低坡度定向／苜蓿叶的8%，再检查高坡度提示。不是每个任意路形都保证在退接上限内有解。

每类先看预览是否完整、汇入方向与曲线是否平顺、车道数是否准确；然后在测试存档确认放置，观察断路／原生报错、实际车道及所有必要转向通行。改变原道路后，旧预览应要求重新生成；取消预览不应修改原路。
