# autochange 三向立交预览与大坡度提示

日期：2026-10-31。分支 `autochange`，版本仍为 `0.0.1-beta`。上一包弯曲核心/涡轮修复已收到用户“验证通过”反馈；本轮继续三向开发，正式放置仍锁定。

## 玩家提示

节点面板的最大坡度超过18%时，立即显示大坡度紧凑方案的无碰撞辅助提示，含中文/英文：正式放置前需要开启无碰撞辅助（如Anarchy），并检查匝道衔接、桥墩和净空，辅助功能不会修正道路形状。

18%为本测试包基于既有使用反馈选用的提示线，不是游戏引擎统一极限。提示不会自动启用、检测或修改其他Mod，也不会屏蔽原版报警、关闭自身安全检查或解锁正式放置。

## 新增节点预览

本轮接入喇叭形、定向T和半定向T。三个方向各选一进一出的双幅开放端点，共六个点；方向1/3是主线两端，方向2是支路。后续主线识别修复允许从任一条臂开始选点，自动规范分组并同步颜色编号，详见《33-autochange三向主线自动识别修复》。主线两端同款同宽同车道；支路可使用不同于主线的断面。同一方向的两幅须匹配。双向单幅、单双幅转换及贯通方向车道变化仍明确拒绝。

- 喇叭形：可切换环道用于出口或入口。
- 定向T、半定向T：可切换两层或三层。两层需要实际地形参考，主线为高架时会提示改用三层。
- 每种三T按真实切点、道路宽度、中分带、车道平衡、交通侧与层高重求模板，保留六个外部端口和六个必要非掉头动作。RHT/LHT与支路位于另一侧均有核心回归覆盖。
- 不强求原路端部切线已严格对向；主线核心采用两端切点中线的割线，支路采用实际切线。新的外部曲线负责接回原路，保留切点、Prefab、实体版本、高程和实际切线。
- 三向的支路进、出路径各可能只有一个外部端口，接路按真实端口连接，不使用四向的取模寻对向关系。原四向入口复用此连接实现，既有回归仍通过。

三T核心目前保持既有模板的解析形态，外部接路适配真实弯曲道路；本轮不宣称其具有四向核心同等的整体弯曲优化。

## 退接与安全约束

沿原路曲线建立每臂独立、道路宽度安全的切点窗口，保留0～1000米用户上限，遇路口或尽头停止。先分别匹配各臂可行窗口，再用最终同一组切点重求核心并检验完整网络；不会用旧参考生成核心后随意换另一组切点。

搜索最多128次附加完整网络尝试，核心试探另有256次、64次工厂调用的硬上限；相同切点向量复用缓存，所有失败无部分网络。额外保留严格最大纵坡（最高30%）、20°逐段切线与前向性、水平节点预留、外接半径认证、8.5米道路净空及真实Prefab支撑规则。

核心端口层高遵循模板语义：定向两种的主支路外端在同一基层，飞越匝道另行分层；喇叭支路外端接较低层。所选原路高程仍由外部坡道精确保留，不能将模板的桥层高度误当全部支路外端高度。

独立复核发现两层下穿曾按局部0米基层平移，可能落在开放路堑深度。现已传递实际地形基准重求：地形100米、基层103米时，主路交叉范围的下穿达到世界87米，即离地至少−13米；缺地形或违反既有高架限制时拒绝。坡度、净空和支撑仍需通过完整认证。

## 游戏测试建议

1. 暂停并选择三方向双幅开放端点，方向1/3主线、方向2支路。先用16%、退接上限1000米、层差自动生成三种T型。
2. 喇叭分别测试“环道出口/入口”；定向、半定向先三层，再在地面主线场景测试两层及完整隧道。高架主线两层应明确拒绝。
3. 试主支路同高与混合高程，观察原端接回、分合流外缘、车道平衡、纵坡、桥墩及原版警告。
4. 将坡度从18%升到19%，确认新提示即时出现；之后恢复需要的坡度。提示不会自动启用无碰撞。
5. 本轮仍只测临时预览。Y型下一阶段单独适配，随后再推进平交和环岛类。
