# autochange 真实原路自动退接

2026-10-30，`autochange`，维持 `0.0.1-beta`。

## 问题与行为

用户日志明确显示 `AttachmentsOutsideApproach`：八个开放节点围出的长度不足，旧工具调用时退接恒为零。现在从选中端点沿真实原路追踪，按照退接量从小到大搜索；默认每臂上限 500 米，可在节点面板调为 0–1000 米，0 为禁用退接。遇到路口、尽头、道路预制体/宽度/方向变化、受其他对象所有权控制的路段或循环就停止，不跨过边界继续外推。

退接点来自实际 Bézier 曲线，包括世界高度和竖向切线。跨度不足时会在真实道路链上切回，临时替换消费掉的原路段，并按原存储方向保留外侧尾段。不同分组的改造范围重叠时拒绝。已有节点坐标与曲线接点分别处理，中间新切点与保留尾段严格共享同一点。所有元数据和预制体先检查，再统一写入预览定义。

宽道路下仅延长主线不能解决直连匝道坡长不足，因此新增了两段圆弧之间的切线连续过渡段；搜索同时选择环道半径、直连半径和过渡长度。不改变玩家指定坡度，30% 仍是上限。每次最多 2048 个候选，预算不足独立报告，不表述为绝对无解。

两条原路已有至少 7.5 米高差时，自动层高分别采用两条原路的平均海拔；否则按界面选择和默认 10 米分层。偏移和手动高差仍可调整。输入仍要求相对臂平直及同路型贯通，复杂弯曲接路属于后续工作。

## 可视化与测试

选中节点的分组色/编号保留；生成成功后白点显示新接点，橙色虚线标出沿原路改造范围，底部显示各方向退接距离和改造段数。原路的临时替换需等待游戏对定义实体生成预览，正式放置仍锁定。

针对测试验证：100 米中心距离的合成小场景先失败，真实链式切回后可在 16% 上限下生成三维候选；支持左右侧通行。另用用户日志八端点的舍入坐标加**合成直线延续**验证零退接失败、自动退接成功、保持 16%、候选预算和范围上限。该回归不证明用户游戏中未读取过的原路曲线已通过。

切回模型验证跨路段、正反存储、边界已有节点、零距离、精确共享切点、越界、太短保留段及无效数据。独立复核发现的已有节点坐标绑定问题和无效零距离输入问题均已修复并复核。UI TypeScript 和本地模拟绑定浏览器交互检查通过，含退接上限调整。完整测试及安装核验结果以最终交付记录为准。

最终记录：完整生成层测试 1290 项通过，无失败或跳过；主 Mod Release 与 UI 构建成功。用户关闭游戏后已部署，26 个安装文件与暂存包 SHA256 一致，版本 `0.0.1-beta`。旧测试包备份 `.artifacts/autochange/installed-before-real-retreat`，安装清单 `.artifacts/autochange/deployment-real-retreat-manifest.json`，测试结果 `.artifacts/autochange/test-results/autochange-real-retreat-final.trx`。未提交或发布，原游戏场景的预览和接路仍待用户验证。
