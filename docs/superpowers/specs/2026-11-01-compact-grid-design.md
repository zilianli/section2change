# 井字立交节点预览设计

用户已确认Y型测试通过并要求继续，沿用已批准方案B与紧凑井字→花形→环岛的顺序。本轮只实现井字可部署预览，版本0.0.1-beta，正式放置锁定，不提交或发布。

## 参考与方法

资产01有52段曲线、8个边界节点。按序列化端点x→y的假设，4个入口各能到达另外3个方向，无掉头。3种Prefab GUID未在游戏解析，不能仅凭GUID声称4/2/1车道已核实；其拓扑可作为参考，生成器必须使用当前道路目录的真实断面。参考资产曲线和图片不打包进Mod。

唯一延续现有方案的实现路线是新建参数化井字核心并重新求解端口，不缩放现成资产，也不将现有定向布局改名。新类型ID CompactGrid，四向节点专用，首页独立入口；自动/手动旧模板不能误用其他类型代替它。

## 拓扑与车道

每方向一进一出的双幅开放道路，共8点。初始支持近直角核心，相对道路同款同宽同车道；接路可处理有界端部偏角与混合高程，原始实体与切线保留。

每条进入道路先分为外侧直行道路与内侧转向集散道，集散道在核心分成左、右两条匝道；另一侧集散道汇入后再与直行合并。每幅N车道满足N=T+2R；集散道2R车道，单条转向R车道。典型4=2+1+1，集散道2车道。必须在目录找到精确车道数、正向、合适宽度的直行和集散Prefab；不静默丢车道。首轮R默认1，可优先采用有效的已有匝道选择，但N必须至少2R+1。每条相对道路的断面和支撑规则一致。

四个直行路径、四个输入集散路径、四个输出集散路径、四个左转、四个右转路径，共20条有向链。8个真实外部端口，12种必要动作，无掉头，逻辑节点与曲线端点精确相同。分合流的外缘偏移采用连续横移并在纵坡变化前留出平坦区。

## 分层与几何

两组相对方向的转向流分别位于低层0/1，两组直行位于层2/3。邻接层差至少满足实际所有参与Prefab的Ground/Elevated包络与8.5米下限；默认至少10米，显式不足的层差拒绝。

外端核心高度取8点平均加基层偏移；最低转向层尽量在其下方半个层差，但不低于参考地形；第二层必须达到高架阈值。原路各端高差由外部接路过渡，不改写选定端点。转向半径、集散道偏距、外侧直行偏距、横移和升降长度依据实际宽度/纵坡重新计算，不能固定采用资产412×416米作为占地保证。

核心先求平面/纵断面，再按真实Prefab桥跨与支撑位置分段。不得用减弱净空、忽略桥墩、隐藏原生错误、扩大预算无上限或放松30%最大纵坡取得预览。每条链必须有序且可认证无自交；整网通过严格纵坡、实际净空及支撑检查才输出。有限备选可调整中心转弯尺度、外侧道路偏距、过渡长度及较缓纵坡。

## 集成与搜索

新EndpointCompactGridCore输出既有EndpointStackCoreResult，复用EndpointCoreAttachment；独立四向有限退接搜索，保留各臂原编号、真实切点与0～1000米上限。核心和附加接路使用同一组切点。失败无部分网络，显示缺少断面/层差/接路/净空/支撑等原因。

UI独立井字入口默认进入点选节点；旧自动/手动按钮对此类型不启用，后端也阻止回落到其他旧模板。提供车道分配、实际道路和四层高度提示，沿用大于18%的无碰撞辅助提示；不强行启用辅助。
