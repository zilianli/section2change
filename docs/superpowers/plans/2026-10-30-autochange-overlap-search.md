# 节点苜蓿叶预览叠放排查与优化

本轮继续已授权的节点模式开发，保持 autochange / 0.0.1-beta，正式放置仍锁定。

1. 用现有宽路端点与真实日志的合成延长道路复现：搜索只检查纵坡，返回的第一个候选可能让直连匝道穿过环道。
2. 添加独立的道路空间检查。使用实际道路宽度和保守曲线净空算法；仅对已知的同一路径连续接头与规定的分合流首末段作局部处理。不能把整条相连道路都排除。
3. 将检查接入候选搜索，冲突和不能确认的候选继续搜索；保留预算和坡度上限，诊断中区分坡度与空间拒绝。
4. 补充节点模式的错误实体定位日志，以便将剩余游戏桥墩错误对应到曲线，而非隐藏游戏错误。
5. 运行左右行、宽路、净空、预算回归与全量测试，独立构建。游戏关闭后部署并核验哈希；游戏实际桥墩与道路警告由下一轮固定预览验证。
