# autochange 首轮游戏点选与预览测试包

用户授权推进到可部署测试版，首轮游戏验收覆盖点选开放节点、按臂归组、输入诊断和苜蓿叶世界坐标预览。正式放置仍须全路网、桥墩、地形及真实原路改造安全检查，当前不开放。维持 v0.0.1beta。

- [x] 先测试再实现只读端点选择状态，支持3/4臂、重复取消、容量、按臂清除。
- [x] 游戏读取真实开放道路端点、切线、预制体、宽度和车道；禁止选择非开放节点和临时实体。
- [x] UI 在自动/手动后加入点选节点，显示当前臂、已选列表和诊断；退出/切类型清空预览。
- [x] 生成前重新读取实体，按真实世界高程生成直线双幅苜蓿叶实验预览；全量检查预制体后再创建临时道路定义。
- [x] 无论 Anarchy 或游戏图标状态如何，本轮都阻止节点模式正式放置。
- [x] 测试、独立复核、Release暂存构建；游戏关闭后部署并核对哈希/版本，给用户具体测试步骤。

完整结果及游戏未验收范围见 `docs/16-autochange首轮游戏测试.md`。实际游戏效果由用户测试，不能将部署成功记作游戏通过。
