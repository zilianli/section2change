# 节点苜蓿叶边缘对齐与车道平衡 Implementation Plan

> 执行已授权的既有功能优化；沿用 section2change 苜蓿叶规则。使用 executing-plans 按任务实现，不提交或发布。

**Goal:** 节点模式苜蓿叶具有外缘对齐、两侧减车道、中央交织段全宽及较圆润的直连匝道。

**Architecture:** 保留独立端点求解器与真实退接，借鉴旧 CloverleafTemplate 的道路边缘与断面规则。区分世界道路曲线与逻辑节点坐标，空间筛选始终检查实际曲线和宽度。

**Tech Stack:** C# netstandard2.0 / net48，既有游戏 NetCourseBuilder，xUnit。

## 既定设计

- 四幅贯通道路分别选择恰好少掉匝道车道数的同类正向单行道路。缺少精确匹配时维持全宽并在面板警告。
- DirectExit → LoopMerge、LoopExit → DirectMerge 为减车道段；LoopMerge → LoopExit 保持全宽。减车道中心向分隔带平移半个宽度差，内缘不动。
- 匝道曲线端点向外平移 `(全宽-匝道宽度)/2`，逻辑连接节点仍使用主线原节点。沿用 section2change 的 NetCourse 节点坐标与曲线坐标分离机制。
- 直连匝道采用短端部圆弧与大半径中间圆弧，切线连续；首末平坡端点位于已避开道路包络处，保持最小分段长度和坡度限制。
- 分合流豁免以逻辑连接节点识别，仅限首末平坡段与相应主线；不得因为外移曲线端点导致全部候选误拒或跳过其他冲突。
- 版本仍为 0.0.1-beta，正式放置锁定。原场景无叠放由用户本轮确认，新的形态和车道连接仍待下一轮游戏验证。
