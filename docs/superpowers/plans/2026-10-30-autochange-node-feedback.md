# 节点反馈与预览触发修复

用户报告八点选齐但无预览，并请求灰色可选节点、选后高亮或编号。截图显示操作和状态位于滚动区下方；日志未含成功记录，但旧版不记录失败，不能认定求解器已执行或能适配该场景。

- 固定底部生成按钮与状态；有效端点选齐时自动尝试一次。每次求解记录快照、各阶段结果和原因。
- 用游戏 OverlayRenderSystem 在鼠标周围显示开放端点：灰色可选、青色悬停、四臂颜色高亮及编号；只读查询，不改变道路实体。
- 周围端点使用原生空间索引、缓存和数量限制，避免每帧扫描整个地图。
- 先测试自动触发/标记状态策略，复测 UI 固定操作和日志；独立复核，完整测试与构建后，游戏关闭时部署。
- 原有正式放置锁继续有效；本轮不将空间不足或不平直输入强行放行。
