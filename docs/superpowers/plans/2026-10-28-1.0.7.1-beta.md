# 1.0.7.1-beta 修复与首轮水域验证

用户已批准：修复审核报告第 1、2 项高严重性问题，进行水中及水陆混合替换首轮测试。禁止自动提交；放置不可撤销，游戏验证须使用复制存档。

1. 用长路、窄交点、多交点回归测试复现固定采样漏检；以贝塞尔控制点包围范围递归分类，统一筛选和切分，边界未决范围保守处理。
2. 接回限定于被改造道路链，携带臂端切线及预制体通行方向，拒绝不兼容候选及歧义。覆盖平行辅路、横向支路、反向单行和正确双向连接。
3. 核验游戏水面 API，保留实际地形离地高度；首轮水中与混合替换测试检查现有桥面参考高度、岸边过渡和水面净空。记录自动测试与游戏实测的区别。
4. 同步版本 1.0.7.1-beta、变更日志及测试报告。运行针对性与全量测试，构建到工作区暂存目录，确认游戏退出后再部署。
5. 独立复核变更，修复新增问题；交付实际验证结果及未通过/待游戏验证项。

边界：不顺带修复报告其他问题；不发布、不提交。水面参考不能替代 NetCourse 的真实地形离地高度；不引入各臂单独扭曲。
