# autochange 弯曲核心与涡轮接入修复

日期：2026-10-31。分支 `autochange`，版本保持 `0.0.1-beta`。正式放置仍锁定。

## 结果与适配方式

节点模式的定向、涡轮已接入section2change现有的 `CurveWarp` 与 `Centerline`。各幅主线、减车道段、相邻匝道和共享节点一起弯曲，避免只调整外部接路而让核心保持直线。

每个候选仍根据实际退接后的对向双幅中点连线确定中心与方向。中心至四个切口按真实端部平均切线构建连续中心线；过紧中心线按150米最小半径认证拒绝。完整、1/2、1/4弯曲强度和直线回退共享原128次完整候选预算及最多8组退接向量。固定模板的参数缓存已复用，避免四种强度重复求解原始模板。

核心变形后重新检查严格纵坡、8.5米道路净空及实际支撑条件。主线断面、车道平衡、原路身份与外部切点保留；面板和日志记录实际是否选用曲线核心，安全回退不会被描述成已弯曲。所有原版报警保留。

## 涡轮叠放定位

本轮游戏日志直接记录了碰撞图标的Target。四条左转匝道上，相邻约2米的两个新节点分别产生桥墩，双方均为 `original=0, flags=Create`。例如节点 `(776.2941,488.6323,-2593.895)` 与 `(777.0106,488.7608,-2595.762)`；这是新桥墩彼此碰撞，不能归因于旧桥墩漏删。

源头为纵断面约2米采样经高度化简后保留了近邻knot，`PlanCuts` 将它们发射为独立道路节点。现在只对实际发射的内部近邻knot尝试删除：修改真实profile、清除高度缓存并复核坡度及沿途净空；不能安全删除时拒绝该候选。末端缓冲区内不发射的knot保留，避免额外改变平段高度。

稳定18%、10米层差、20米双幅/16米减道/8米匝道回归已消除原约2米短段。弯曲后的四组实际导出中，最短匝道节点间距约9.93～12.63米；这说明短节点源头已改善，仍需原版桥墩生成结果验收。

## 右转接入修复

涡轮右转原先漏用了普通定向已有的 `RightAttach` 外缘对齐，按主路中心线接入。现在20米主路与8米匝道按6米曲线中心偏移接到外侧车道，同时保留原共享逻辑节点；端部小弧按真实剩余横移量计算。

保留左、右转接入顺序、实际并行重叠及净空要求。较长接点间隔需要额外主路桥节点时，按既有20米节点预留处理；半径搜索由8%细化到2%。原1米分段网格找不到窄合法区间时，补查禁区边界，所有跨度、最短长度及禁区条件仍适用。

稳定正交完整解：右转汇入沿道路位置约 `351.335→343.136米`，提前约8.20米；末端小弧半径约 `88.971→137.5米`。这是完整模板解的结果，不采用早期单臂探针曾显示的12米提前量。
